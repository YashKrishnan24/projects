# Software Development Projects

Welcome to the central repository for my software development projects. This collection highlights a range of applications, from full-stack web platforms and real-time collaborative tools to interactive game development and modern UI/UX implementations.

## 🚀 Featured Projects

### 1. Real-Time Collaborative Workspace
A highly interactive application designed for live collaboration, similar to a shared whiteboard or document editor.
* **Tech Stack:** MongoDB, Express, React, Node.js (MERN), Socket.io, WebSockets
* **Features:** Live synchronized editing, persistent state management, and low-latency client-server communication.

### 2. E-Commerce Platform
A scalable storefront application with a focus on modern design and seamless user experience.
* **Tech Stack:** MERN Stack, Redux, Tailwind CSS (v4), Vite, Stripe API
* **Features:** Dynamic product filtering, persistent shopping cart functionality, and secure payment integration.

### 3. The Great Gravity Glitch
An interactive arcade-style game demonstrating object-oriented programming and game loop mechanics.
* **Tech Stack:** Java
* **Features:** Custom physics interactions, collision detection, and scoring mechanics.

### 4. Glassmorphism Email Submission Page
A frontend component showcasing contemporary web design trends for college society feedback portals and general contact forms.
* **Tech Stack:** HTML, Tailwind CSS, JavaScript
* **Features:** Glassmorphism aesthetics, responsive layouts, and interactive UI elements.

## 🛠️ Technologies & Tools

* **Frontend:** React, Tailwind CSS, Vite, Redux
* **Backend:** Node.js, Express, Socket.io
* **Databases:** MongoDB
* **Languages:** JavaScript, Java, Python
* **Development Environment:** VS Code
